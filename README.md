# RPG Building Library

Public static gallery and command reference for our Craft to Exile 2 server.

- `index.html`: 4,071 catalog entries with previews, filters, original source links, and copyable WorldEdit commands.
- `commands.html`: server-specific building command reference.
- `rpg-previews/`: simplified block-model preview images.

Build credits and source links are preserved on individual cards. Some imported structures are rooms or modules. In-game testing status is described on the pages. Server files, credentials, and schematic payloads are not included.

Source pages: `D:/mc-server-setup/docs/`. Hosted with GitHub Pages from the main branch root.
